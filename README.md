# Ripple

## Summary

This package is an attempt to solve/speedup various annoyances that DJs encounter while using rekordbox. 

## Issues encountered in rekordbox this package solves

If you use tracks streamed from tidal, it's common for Tidal's music catalog to change frequently. This can cause some issues because tidal tracks that you may have added to your rekordbox collection can fail to load with the message "You are not connected to the internet". Despite this obstruse error message, the real issue is that certain tracks under a certain tidal ID get deleted, and relisted under a new ID. Then when your collection goes to load that track that was relisted, it cannot find it, and fails to load it. Without this tooling, its necessary to re-search for the track under the tidal sub-panel in rekordbox, find it again, and transfer all of your tagging information to the fresh identical tidal track, then delete the old one. 

## Tools vended

 - `analyze-tidal-tracks` is a tool designed to automate this track rediscovery process as far as possible. It finds all the tidal tracks in your rekordbox library, determines if they're stale by reconciling them against the remote tidal catalog, and if they are, it searches for an identical replacement track automatically, prompting the user to confirm each replacement. It then edits the stale track in your rekordbox library to point to the new one. The roadmap for this tool includes ISRC linking, such that after the first round of manually confirming that the song that the tool found to replace the stale one is indeed the correct one, the ISRC of that track is then used for all future stale-to-fresh remappings, instead of standard text search. This will provide greater collection stability, as ISRCs are unique to a specific sound recording and thus, are very stable.

## Installation

> [!WARNING]
> Please note that this package is currently only compatible with python 3.13. This is because above Python 3.13, no precompiled wheels for PyAudio are available, and compiling from source fails due to old headers that are also no longer standard in Cython implementations. This limitation may be removed in the future if PyAudio is no longer needed.

In order for this package to function, as mentioned above, python 3.13 is required. If you do not already have it, you can install it with the command (assuming you already have the general python runtime)
```
py install 3.13
```

In the root of the project directory, run
```
py -3.13 -m venv .venv
```

This creates a folder where all information python needs to manage your virtual environment is stored. Activate this virtual environment with the script compatible for your system's flavor located under `{YOUR_VENV_NAME}/scripts` by running the appropriate script from the command line. You should see the name of the virtual environment in parentheses by the start of the command line prompt if the script ran successfully. First, install all regular package dependencies in `requirements.txt`. If you intend to modify this package, you should also install all packages in `dev-requirements.txt`. Run the following command for requirements.txt (and dev-requirements.txt, if needed).
```
python -m pip install -r requirements.txt
```


## Subtool related installations


### Tidal

If you intend to use any tidal streaming related subtools (e.g. `analyze-tidal-tracks`) , download the autogenerated tidal api client for python from the repository [here](https://github.com/wfehrnstrom/python-tidal-openapi). Then install it in editable mode. You should have already activated the virtual environment for ripple in order to download ripple's python dependencies. Keep it active.

Navigate to the root directory where you placed `python-tidal-openapi` and run `python -m pip install -e .`. This command installs all subdependencies of python-tidal-openapi and makes its code discoverable to the python runtime from ripple. This step is only currently needed because `python-tidal-openapi` is not yet listed on pip.

To use any tidal related subtools in ripple, you will need a tidal account. Go to [the tidal developer home page](https://developer.tidal.com/) and login using your account details. Go to dashboard and create a new app, calling it anything you want, and grab the client ID and client secret that the page now displays. 

Create a folder under at the root level of this project called `secrets` and add a file called `client-credentials.json` within `secrets`. It should look like this:

```
{
    "client_id": "YOUR_CLIENT_ID_HERE",
    "client_secret": "YOUR_CLIENT_SECRET_HERE"
}
```

You're now ready to take advantage of the tools this package has to offer. Happy DJing!
